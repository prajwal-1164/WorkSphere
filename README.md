# WorkSphere

A starter full-stack project and task management workspace using React, Vite, Node.js built-in HTTP server, and SQLite. No Express or MongoDB.


## Run locally
1. Install Node.js LTS.
2. In this folder, run `npm install`.
3. Run `npm run dev`.
4. Open `http://localhost:5173`.

Frontend runs on port 5173; API runs on port 5000. API health check: `http://localhost:5000/api/health`.


## Features in this starter
- Dashboard overview
- Project creation (saved to SQLite when backend is running)
- Task creation, status update, delete
- Search task list
- Responsive layout and sidebar navigation


## Tech stack
React, JavaScript, Vite, Node.js HTTP, SQLite, lucide-react.
